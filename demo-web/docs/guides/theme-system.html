Style with the Kolt Theme System

Understand and apply the layout, color, shape, and typography standards provided by the compose-kmp utility module.

Introduction

Kolt’s visual system is built on top of Material 3 but customizes core shapes and typography to deliver a premium, refined feel. The system centers around G2 Curvature Continuity for smooth corners, tailored typography scaling, fluent style property extensions, and unified light/dark mode support.

1. Smooth Corners (G2 Curvature Continuity)

Traditional rounded corners (standard CSS or basic Compose RoundedCornerShape) suffer from "corner breaks" — abrupt changes in math curvature where the straight edge transitions into the circle arc. Kolt uses a mathematically continuous cubic blending formula via SmoothCornerShape (squircles) to avoid this visual friction.

Standard Circle Arc:  ───╮ (Hard math curve transition break)
Curvature Continuous:  ───⏏ (Mathematically smooth G2 transition)

Apply smooth corners directly via modifiers or container cards:

// 1. Modifier Clip
Box(
    modifier = Modifier
        .size(120.dp)
        .clip(SmoothCornerShape(radius = 24.dp, smoothness = 0.55f))
        .background(Kolt.colors.primary)
)

// 2. TitledCardView wrapper (automatically implements G2 corners)
TitledCardView(title = UiText.DynamicString("Card Title")) {
    Text("This card has smooth corners.")
}

2. The Color System (Exhaustive Tokens)

Colors are organized into semantically grouped tokens, exposed through the Kolt.colors object. This allows components to automatically adjust their contrast and values when switching between light and dark modes.

Core Brand Palette

  • primary / onPrimary: Core brand accent color. Used on major triggers, focus rings, and filled action buttons.
  • secondary / onSecondary: Subdued actions, outlined buttons, and secondary borders.
  • tertiary / onTertiary: Tertiary accents and warning highlights.

Layout Surfaces & Boundaries

  • background / onBackground: Underlying window background behind all scroll areas and views.
  • mainSurface / onMainSurface: Layout containers, sidebar menus, and parent pages.
  • secondarySurface / onSecondarySurface: Sub-panels, drawer details, and inner content regions.
  • dividerColor (also aliased as outline): Used for divider lines, spacers, and card borders.
  • scrimColor: Overlay dims behind bottom sheets, dialog modals, and navigation drawers.

Card Containers

  • primaryCardContainer / onPrimaryCardContainer: Filled containers for active elements.
  • secondaryCardContainer / onSecondaryCardContainer: Filled containers for supporting details.
  • tertiaryCardContainer / onTertiaryCardContainer: Alternating container fills.
  • greyCardContainer / onGreyCardContainer: Muted neutral container panels.
  • errorCardContainer / onErrorCardContainer: Container fills for input error states.

Specialized Text Accents

Direct typography overrides for highlights and links:

  • accentedBlueText (aliased as accentedBlue): Hyperlinks and clickable inline prompts.
  • accentedGoldText (aliased as accentedGold): Interactive rating stars and confirmation badges.
  • disabledText / subText / hintText: Successive gray-scaled tiers of secondary text.
  • accentedBlueTitle / accentedBlackTitle / accentedRedTitle: Focused header accents.

Semantic State Intents

Semantic state colors represent system feedback, typically backing components like AppsStatusTag, AppsBadge, or AppsBanner:

  • Success State: successContainer & onSuccessContainer (defaults to primary card containers).
  • Warning State: warningContainer & onWarningContainer (defaults to tertiary card containers).
  • Info State: infoContainer & onInfoContainer (defaults to secondary card containers).
  • Error State: errorContainer & onErrorContainer (defaults to error card containers).
// Usage in a Composable
Box(
    modifier = Modifier
        .background(Kolt.colors.mainSurface)
        .border(1.dp, Kolt.colors.outline, RoundedCornerShape(8.dp))
) {
    Text(
        text = "Hello World",
        color = Kolt.colors.onMainSurface
    )
}

4. Fluent Weight & Style Extensions

Rather than calling copy(...) manually to adjust style weights or styles, Kolt provides properties as direct extensions on TextStyle. These can be chained fluently in standard Kotlin:

Font Weights

  • .thin → FontWeight.Thin (100)
  • .extraLight → FontWeight.ExtraLight (200)
  • .light → FontWeight.Light (300)
  • .normal → FontWeight.Normal (400)
  • .medium → FontWeight.Medium (500)
  • .semiBold → FontWeight.SemiBold (600)
  • .bold → FontWeight.Bold (700)
  • .extraBold → FontWeight.ExtraBold (800)
  • .black → FontWeight.Black (900)

Italic Variations

You can make any style italic with .italic, or set weight and style in one step:

  • .thinItalic, .extraLightItalic, .lightItalic, .mediumItalic, .semiBoldItalic, .boldItalic, .extraBoldItalic, .blackItalic

Platform Font Padding (Zero-Padding Adjustments)

To eliminate vertical padding offsets introduced by Android or iOS fonts, chain .noPadding. This forces the system layout engine to compute vertical bounds tightly around the glyph cap height.

// Usage Example
Text(
    text = "CHALLENGE",
    style = Kolt.typography.textGiant.blackItalic.noPadding
)

5. Font Families & AppFont Configuration

The system theme font is defined at the root using the AppFont sealed class. You can customize the font family across the entire composable hierarchy, or apply localized overrides on specific elements.

One-off overrides

Apply specific font families directly on a single text element using property extensions:

  • .roboto → Forces Noto Sans / Roboto (bundled offline).
  • .noto → Forces Noto Sans (bundled offline, ideal for Indic scripts like Malayalam, Hindi, Tamil).
// Override on a single text element
Text(
    text = "മലയാളം",
    style = Kolt.typography.bodyMedium.noto
)

The AppFont Configuration Options

Kolt supports 4 ways to configure fonts across your entire application root via the AppFont class:

  • AppFont.Roboto: Offline-bundled Roboto font. All 9 weights are registered and load instantly without system or network dependencies (Default).
  • AppFont.Noto: Offline-bundled Noto Sans. Recommended for Indian localization. The MalayalamCompositionBaseProvider defaults to this font family.
  • AppFont.Google("Font Name"): Dynamically downloads the requested font from the Google Fonts directory at runtime using Google Play Services. For example, AppFont.Google("Inter") or AppFont.Google("Poppins").
  • AppFont.Google("Outfit"): Load Outfit via Google Fonts (Requires Play Services).
  • AppFont.Custom(family: FontFamily): Pass in your own pre-built FontFamily (loading local resource assets or downloadable font resources).

Configuring the Root Provider

To configure your app-wide font family, pass the font parameter to your root composition provider:

// 1. Standard App Setup using a Google Font
@Composable
fun AppRoot() {
    CompositionBaseProvider(
        font = AppFont.Google("Inter")
    ) {
        MainAppContent()
    }
}

// 2. Malayalam Localization using Noto Sans
@Composable
fun LocalizedAppRoot() {
    MalayalamCompositionBaseProvider(
        font = AppFont.Noto
    ) {
        MainAppContent()
    }
}

6. Theme Switching (Light/Dark Mode)

Kolt supports dynamic light/dark mode theme switching via the KoltTheme composable. Wrap your application navigation and supply the mode parameter:

// AppEntry.kt
@Composable
fun AppEntry(settingsViewModel: SettingsViewModel = viewModel()) {
    val isDarkMode by settingsViewModel.isDarkMode.collectAsState()

    KoltTheme(darkTheme = isDarkMode) {
        AppNavigation()
    }
}
