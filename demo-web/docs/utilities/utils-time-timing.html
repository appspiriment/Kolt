Library: utils

Date, Time & Timing Utilities

Implement thread-safe time formatting, timezone conversions, relative time offsets, decimal hour calculations, and traditional Vedic Nazhika timing on Android.

1. Formatter Caching (Performance)

Creating Java DateTimeFormatter instances repeatedly is a heavy operations. Kolt optimizes this by caching compiled patterns inside a thread-safe ConcurrentHashMap:

// Retrieves or compiles the pattern once, caching it automatically:
val formatter = formatterFor("yyyy-MM-dd HH:mm:ss")

2. LocalDate Extensions

Extensions on Java 8 LocalDate to format dates quickly using localized styles:

  • LocalDate.formatDisplay(): Formats the date into a standard reader style: 
    val date = LocalDate.of(2026, 6, 21)
date.formatDisplay() // returns "21 Jun 2026" (English locale)
  • LocalDate.formatDateTime(): Appends time components, returning a standardized display string: 
    date.formatDateTime() // returns "21 Jun 2026, 00:00"
  • LocalDate.toEpochMillis(): Converts the date boundary into raw milliseconds since Unix epoch (UTC midnight).
  • Long.toLocalDateTime(): Extension on Long epoch stamps to reconstruct standard LocalDateTime instances.

3. Relative Time Conversions

Converts date/time instances into dynamic, human-readable relative time intervals:

  • LocalDateTime.toRelativeTime(): 
    val past = LocalDateTime.now().minusHours(3)
past.toRelativeTime() // returns "3 hours ago"

val future = LocalDateTime.now().plusDays(2)
future.toRelativeTime() // returns "in 2 days"

val justNow = LocalDateTime.now().minusSeconds(10)
justNow.toRelativeTime() // returns "Just now"

4. Decimal Hour Conversions

Useful for calculating task durations, astronomy computations, or time-tracking cards:

  • Long.millisToDecimalHour(): Converts epoch milliseconds into decimal hours (e.g. 3_600_000L → 1.0).
  • Long.millisToDays(): Converts milliseconds into decimal day counts.
  • Double.fromHoursToMillis(): Converts decimal hours back into milliseconds.
  • Double.fromHoursToHMS(): Splits decimal hours into a Triple of (Hours, Minutes, Seconds): 
    val hms = 2.50.fromHoursToHMS() // returns Triple(2, 30, 0) -> 2 hours, 30 minutes, 0 seconds

5. Vedic Time (Nazhika & Vinazhika)

Vedic time (commonly used in Kerala and other parts of India for traditional calendar calculations, astrological schedules, and astronomical maths) divides a 24-hour day into 60 Nazhika (നാഴിക). 1 Hour is equivalent to exactly 2.5 Nazhika. A single Nazhika is further divided into 60 Vinazhika (വിനാഴിക).

Kolt provides precise conversion helpers between standard decimal hours and traditional Vedic scales:

  • Double.fromHoursToNazhika(): Converts decimal hours to a Pair of (Nazhika, Vinazhika): 
    val (nazhika, vinazhika) = 1.0.fromHoursToNazhika() // 1 Hour -> Pair(2, 30) -> 2 Nazhika, 30 Vinazhika
  • Double.hourstoNazhikaVinazhikaString(): Formats hours directly into a Malayalam Vedic label: 
    2.0.hourstoNazhikaVinazhikaString() // returns "5 നാ 0 വി" (5 Nazhika, 0 Vinazhika)
  • Double.nazhikaToNazhikaVinazhika(): Converts a decimal Nazhika count into a Pair of (Nazhika, Vinazhika).
  • Double.nazhikatoNazhikaVinazhikaString(): Formats a decimal Nazhika value into a Malayalam string: 
    4.25.nazhikatoNazhikaVinazhikaString() // returns "4 നാ 15 വി"

6. Epoch to Date Conversions

  • Long.millisToDateTime(format: String, timeZone: ZoneId): Directly formats epoch milliseconds into custom formatted date-time strings, resolving offsets correctly. Returns null if formatting fails. 
    val text = epochMillis.millisToDateTime("yyyy/MM/dd HH:mm", ZoneId.of("Asia/Kolkata"))
