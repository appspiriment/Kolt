Library: compose-utils

System Permissions & Photo Pickers

Request Android system permissions inline in your Composables and trigger the system Photo Picker with custom selection limits.

1. PermissionHandler (Runtime Permissions)

Handling Android runtime permissions usually requires registering an activity result launcher, checking states, managing rationales, and handling permission request callbacks. Kolt wraps this inside a single, clean Composable component.

Core API

@Composable
fun PermissionHandler.Request(
    permissions: List<String>,
    onGranted: () -> Unit,
    onDenied: (deniedPermissions: List<String>) -> Unit
)

Usage Example

Place the PermissionHandler.Request inside your Composable tree. Trigger its execution by conditionally mounting it when permissions are required:

@Composable
fun CameraFeature(viewModel: FeatureViewModel = viewModel()) {
    val requestPermission by viewModel.permissionRequested.collectAsState()

    if (requestPermission) {
        PermissionHandler.Request(
            permissions = listOf(Manifest.permission.CAMERA, Manifest.permission.RECORD_AUDIO),
            onGranted = {
                // Executed when all requested permissions are approved
                viewModel.onPermissionGranted()
                openCameraRecorder()
            },
            onDenied = { deniedList ->
                // Executed if one or more permissions are rejected
                viewModel.onPermissionDenied(deniedList)
                showFallbackMessage()
            }
        )
    }
}

2. PhotoPicker Launcher

Launches the official system Photo Picker interface (which doesn't require requesting storage permissions on modern Android versions). It retrieves media Uri coordinates to read or upload files.

Core API

@Composable
fun rememberPhotoPickerLauncher(
    onResult: (uris: List<Uri>) -> Unit
): PhotoPickerLauncher

Usage Example

@Composable
fun ProfileAvatarEdit(viewModel: AvatarViewModel = viewModel()) {
    // 1. Initialise the launcher with a result callback
    val pickerLauncher = rememberPhotoPickerLauncher { uris ->
        if (uris.isNotEmpty()) {
            val selectedPhotoUri = uris.first()
            viewModel.updateAvatar(selectedPhotoUri)
        }
    }

    // 2. Trigger picker from buttons or click modifiers
    AppsButton(
        text = "Select Profile Photo".toUiText(),
        onClick = {
            // Limits selection to a single photo
            pickerLauncher.launch(maxItems = 1) 
        }
    )
    
    AppsButton(
        text = "Select Gallery Images".toUiText(),
        onClick = {
            // Allows selecting up to 8 items in the picker
            pickerLauncher.launch(maxItems = 8) 
        }
    )
}
