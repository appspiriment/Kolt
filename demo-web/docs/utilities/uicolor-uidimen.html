Library: compose-kmp

UiColor & UiDimen

Abstract Compose-native colors, XML resource specifications, and lengths/fonts in common business models, resolving them dynamically at runtime.

1. Overview: Abstracting Layout & Theme Variables

To design highly customized views in KMP projects, ViewModels or domain controllers must frequently express styling variables—such as custom tag borders, brand highlights, dynamic container padding, or user-selected font sizes. However, standard Compose classes like Color, Dp, and TextUnit (sp) are not easily serializable or translatable across platform-dependent configuration resources (e.g. Android XML colors.xml and dimens.xml).

Kolt addresses this by introducing UiColor and UiDimen wrappers. They unify raw runtime properties and static file resources under serializable, testable models that resolve instantly inside Composable functions.

2. UiColor (Color Wrapper)

UiColor manages standard Compose color objects, color XML resource identifiers, and hex code strings.

Class Definition & Subclasses

package io.github.appspiriment.kolt.composekmp.wrappers

sealed class UiColor {
    companion object {
        val Black = DynamicColor(Color.Black)
        val White = DynamicColor(Color.White)
        val Transparent = DynamicColor(Color.Transparent)
        val Unspecified = DynamicColor(Color.Unspecified)
    }

    data class DynamicColor(val value: Color) : UiColor()
    class ColorResource(val resId: Int) : UiColor()
    data class HexColor(val hex: String) : UiColor() {
        init {
            require(hex.matches(Regex("^#([A-Fa-f0-9]{6}|[A-Fa-f0-9]{8})$"))) {
                "Invalid hex color format. Must be #RRGGBB or #AARRGGBB"
            }
        }
    }
}

Factory Functions & Extensions

Quickly convert platform variables into UiColor instances:

Color.Red.toUiColor()                     // -> UiColor.DynamicColor
R.color.brand_blue.toUiColorResource()    // -> UiColor.ColorResource
"#34A853".toUiColorHex()                  // -> UiColor.HexColor
uiColorResource(R.color.background_dark)  // Composable helper

Resolving inside Composables

To resolve the wrapped value into a standard Compose-native color, use the following Composable extension:

val color: Color = uiColor.asColor()

3. UiDimen (Dimension Wrapper)

UiDimen represents lengths, spacings, padding intervals, and font sizes (sp) from raw floats or resource structures.

Class Definition & Subclasses

package io.github.appspiriment.kolt.composekmp.wrappers

sealed class UiDimen {
    data class DynamicDp(val value: Dp) : UiDimen() {
        companion object {
            val Zero = DynamicDp(0.dp)
            val Unspecified = DynamicDp(Dp.Unspecified)
        }
    }

    data class DynamicTextUnit(val value: TextUnit) : UiDimen() {
        companion object {
            val Unspecified = DynamicTextUnit(TextUnit.Unspecified)
        }
    }

    class DimenResource(val resId: Int) : UiDimen()
}

Factory Functions & Extensions

16.dp.toUiDimen()                         // -> UiDimen.DynamicDp
14.sp.toUiDimen()                         // -> UiDimen.DynamicTextUnit
R.dimen.padding_large.toUiDimenResource() // -> UiDimen.DimenResource
uiDimenResource(R.dimen.spacing_small)    // Composable helper

Resolving inside Composables

Resolve dimensions and font sizes using these Composable extensions:

val padding: Dp = uiDimen.asDp()
val fontSize: TextUnit = uiDimen.asSp()

4. Complete Code Example

This implementation showcases how to pass dynamic borders, background colors, and margin spacing from a common data structure to build a customizable UI banner.

1. Styling Configuration Model (commonMain)

import io.github.appspiriment.kolt.composekmp.wrappers.UiColor
import io.github.appspiriment.kolt.composekmp.wrappers.UiDimen
import io.github.appspiriment.kolt.composekmp.wrappers.toUiColorHex
import io.github.appspiriment.kolt.composekmp.wrappers.toUiDimen
import androidx.compose.ui.unit.dp

data class BannerStyle(
    val backgroundColor: UiColor,
    val outlineColor: UiColor,
    val paddingSize: UiDimen
)

class AlertController {
    val successBanner = BannerStyle(
        backgroundColor = "#E6F4EA".toUiColorHex(), // Light Green Hex
        outlineColor = "#137333".toUiColorHex(),    // Dark Green Hex
        paddingSize = 16.dp.toUiDimen()            // Raw 16dp spacing
    )
}

2. Composable Component (commonMain UI)

import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import io.github.appspiriment.kolt.composekmp.wrappers.asColor
import io.github.appspiriment.kolt.composekmp.wrappers.asDp

@Composable
fun StyledAlertBanner(style: BannerStyle, message: String) {
    Box(
        modifier = Modifier
            .border(
                width = 1.dp,
                color = style.outlineColor.asColor() // Resolves border color
            )
            .background(
                color = style.backgroundColor.asColor() // Resolves background color
            )
            .padding(
                all = style.paddingSize.asDp() // Resolves padding intervals
            )
    ) {
        Text(text = message, color = style.outlineColor.asColor())
    }
}
