Library: utils

AsyncState & Flow Utilities

Standardize async operations, lifecycle-aware flow caching, debouncing, and automated state collection inside your ViewModels and repository flows.

1. AsyncState Machine

The AsyncState sealed class provides a structured state machine to model asynchronous data fetching. It replaces multiple booleans (like isLoading, isError) with a single, type-safe value.

Class Definition

sealed class AsyncState<out T> {
    data object Idle : AsyncState<Nothing>()
    data object Loading : AsyncState<Nothing>()
    data class Success<T>(val data: T) : AsyncState<T>()
    data class Error(val throwable: Throwable) : AsyncState<Nothing>()
}

Core API Usage

View models expose AsyncState, which UI components (like AsyncStateBox) collect and render automatically:

// viewModel (commonMain)
class DashboardViewModel : ViewModel() {
    private val _userState = MutableStateFlow<AsyncState<User>>(AsyncState.Idle)
    val userState: StateFlow<AsyncState<User>> = _userState

    fun loadUser() {
        _userState.value = AsyncState.Loading
        try {
            val user = repo.fetchUser()
            _userState.value = AsyncState.Success(user)
        } catch (e: Exception) {
            _userState.value = AsyncState.Error(e)
        }
    }
}

2. Flow Lifecycle Extensions

Exposed through FlowUtils.kt, these extension functions optimize flow sharing across your application so threads and resources are only active when needed.

stateInWhileSubscribed

Converts a cold flow into a hot StateFlow that caches its value but stops collecting from upstream sources 5 seconds (5000ms) after the last UI collector detaches. This survives device rotation while freeing background DB connections during app suspension.

val hotStateFlow: StateFlow<AsyncState<Data>> = coldFlow
    .stateInWhileSubscribed(
        scope = viewModelScope,
        initialValue = AsyncState.Idle
    )

shareInWhileSubscribed

Converts a cold flow into a hot SharedFlow (ideal for one-shot event emitters) using the same 5-second timeout subscription policy.

val eventFlow: SharedFlow<SystemEvent> = rawEventFlow
    .shareInWhileSubscribed(scope = viewModelScope)

3. Debouncing & Collecting

debounceAndCollect

Shorthand operator combining Flow debouncing (rate limiting) with lifecycle collection. Extremely useful for implementing search inputs or dynamic sliders to prevent server flooding.

// commonMain search input flow
queryFlow.debounceAndCollect(
    timeoutMillis = 400L,
    scope = coroutineScope
) { query ->
    // Executed only after 400ms of user typing silence
    runSearchQuery(query)
}

4. Flow Collection State Wrappers

To reduce coroutine boilerplate inside screens or presenters, Kolt offers automated state collectors that stream flow updates directly into multiple target StateFlow registers.

collectState

Launches a collection thread on the target dispatcher (defaults to Dispatchers.Default) and feeds success, loading, or exception results directly into target MutableStateFlow registers or listener lambdas.

// Binds flow states directly to View Model state registers:
repository.getUserFlow()
    .collectState(
        scope = viewModelScope,
        successState = _userState,
        errorState = _errorMessageState,
        loadingState = _loadingProgressState,
        cancelAfterFirst = false // set true to auto-close collection after first Success
    )

collectFlows

Launches a launched block to collect flow emissions safely, exposing standard onNext, onError, and onLoading listener hooks.

repository.getItemsFlow()
    .collectFlows(
        scope = viewModelScope,
        onNext = { items -> processItems(items) },
        onError = { err -> showErrorDialog(err) },
        onLoading = { isLoading -> toggleProgress(isLoading) }
    )
