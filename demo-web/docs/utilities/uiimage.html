Library: compose-kmp

UiImage

Unify static vectors, traditional platform drawables, runtime painters, and remote HTTP images under a single multiplatform class, loaded smoothly via the Coil engine.

1. Overview & Abstracting Graphics

Similar to strings, loading graphic assets inside shared KMP modules is challenging. Different platforms use distinct graphic formats—Android uses resource drawable integer IDs (e.g. R.drawable.avatar) or XML vectors, iOS uses native named assets, and desktop targets often load raw raster images.

UiImage abstracts these variations. It provides a common API to represent any image source. Additionally, it features built-in support for remote HTTP images, integrating directly with the Coil image-loading engine. ViewModels in commonMain can yield network images with localized resource placeholders and error configurations, which resolve seamlessly when drawn.

2. Class Definition & Subclasses

UiImage is defined as a sealed class holding the graphic details, an accessibility content description, and an optional color overlay tint.

package io.github.appspiriment.kolt.composekmp.wrappers

sealed class UiImage(
    open val description: String?,
    open val tint: UiColor?
) {
    abstract fun setDescription(contentDescription: String?): UiImage
    abstract fun setTint(tint: UiColor? = null): UiImage
    
    // ... subclasses
}

3. Fluent Chaining Methods

Every UiImage subclass implements functional chaining methods to modify its accessibility description or color tint at the call-site without losing the underlying resource details:

val originalIcon = uiVectorResource(R.drawable.ic_check)

// Apply tint and description dynamically:
val styledIcon = originalIcon
    .setDescription("Item Checked")
    .setTint(Kolt.colors.success.toUiColor())

4. Factory Functions

Construct UiImage references in shared or platform source sets using these concise factory APIs:

// 1. Static resources:
imageVector.toUiImage()                         // ImageVector -> UiImage.ImageVectorIcon
uiImageResource(R.drawable.avatar_placeholder)  // Int drawable ID -> UiImage.DrawableResourceIcon
uiVectorResource(R.drawable.ic_logo_vector)     // Int XML vector -> UiImage.VectorResourceIcon
painter.toUiImage()                            // Painter -> UiImage.PainterIcon

// 2. Coil-backed remote URLs:
uiImageFromUrl(
    url = "https://example.com/profile.jpg",
    placeholder = uiImageResource(R.drawable.placeholder_user),
    error = uiImageResource(R.drawable.error_connection)
)

// 3. Generic Coil loader (accepts files, URIs, byte arrays, etc.):
uiImageRemote(
    model = fileObject,
    crossfade = true,
    memoryCacheKey = "user_cached_avatar"
)

5. Resolving in UI Composables

To render a UiImage on a screen, call the following Composable extension functions:

  • UiImage.getPainter(): Painter: Resolves the image source and returns a Compose-ready Painter. If it is a RemoteImage, it handles asynchronous HTTP fetching, caching, crossfading, and displaying placeholder/error states automatically.
  • UiImage.getImageVector(): ImageVector?: Extract the underlying ImageVector directly (applicable only to vector icons). Returns null for raster images or remote URLs.

6. Complete Code Example

The following example defines a remote contact avatar card with a local vector placeholder fall-back.

1. ViewModel (commonMain)

import io.github.appspiriment.kolt.composekmp.wrappers.UiImage
import io.github.appspiriment.kolt.composekmp.wrappers.uiImageFromUrl
import io.github.appspiriment.kolt.composekmp.wrappers.uiVectorResource

data class ContactUiState(
    val displayName: String,
    val avatar: UiImage
)

class ContactViewModel : ViewModel() {
    val contactState = ContactUiState(
        displayName = "David Lee Kolt",
        avatar = uiImageFromUrl(
            url = "https://avatars.githubusercontent.com/u/123456",
            placeholder = uiVectorResource(R.drawable.ic_contact_placeholder),
            error = uiVectorResource(R.drawable.ic_contact_error_fallback)
        )
    )
}

2. Composable View (commonMain UI)

import androidx.compose.foundation.Image
import androidx.compose.foundation.layout.Row
import androidx.compose.foundation.layout.size
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import io.github.appspiriment.kolt.composekmp.wrappers.getPainter

@Composable
fun ContactCard(viewModel: ContactViewModel) {
    val state = viewModel.contactState

    Row(modifier = Modifier.padding(16.dp)) {
        Image(
            painter = state.avatar.getPainter(),
            contentDescription = state.avatar.description ?: "User Profile Avatar",
            modifier = Modifier.size(64.dp)
        )
        Text(text = state.displayName, style = Kolt.typography.bodyLarge)
    }
}
