Library: utils

String, Phone & Validation Utilities

Implement client-side form validation, international phone formatting, character constraints, password strength meters, and card verification inside common business logic.

1. String Extensions

Direct Kotlin property extensions on String that simplify day-to-day text formatting operations:

  • String.capitalizeWords(): Capitalizes the first character of each word in the string. 
    "kotlin multiplatform developer".capitalizeWords() // returns "Kotlin Multiplatform Developer"

2. Validation Utilities

Simple regex-based validators that return a Boolean flag:

  • String.isValidEmail(): Checks if the input matches a standard email format (trims whitespace automatically).
  • String.isValidPhone(): Checks if the phone number string contains valid character sets (digits, spaces, dashes, +, parentheses).
  • String.isValidUrl(): Case-insensitive URL validation. Supports standard http, https, and ftp schemes.
  • String.isValidIndianPinCode(): Validates Indian 6-digit postal PIN codes. Ensures it does not start with 0.
  • String.isValidUsZipCode(): Validates US 5-digit zip codes (with support for optional +4 extension).
val email = "arun@appspiriment.io"
if (email.isValidEmail()) {
    proceedLogin()
}

3. String Length Checks

  • String.hasMinLength(min: Int): Returns true if the string length is greater than or equal to min.
  • String.hasMaxLength(max: Int): Returns true if the string length is less than or equal to max.
  • String.hasLengthInRange(min: Int, max: Int): Checks if the string length is within the range [min, max].

4. Character Validation Helpers

Quickly confirm input characters without complex loop scripts:

  • String.hasOnlyLetters(): True if all characters are alphabetic.
  • String.hasOnlyDigits(): True if all characters are numeric digits.
  • String.hasOnlyAlphanumeric(): True if all characters are letters or digits.
  • String.hasNoSpecialChars(): True if characters are alphanumeric or space characters (no punctuation).

5. Password Strength Meter

Security validation helpers for user onboarding flows:

  • String.hasUppercase(): True if the string contains at least one uppercase letter.
  • String.hasLowercase(): True if the string contains at least one lowercase letter.
  • String.hasDigit(): True if the string contains at least one digit.
  • String.hasSpecialChar(): True if the string contains a non-alphanumeric special character.
  • String.passwordStrength(): Returns a score from 0 (weakest) to 4 (strongest). It checks: length ≥ 8 (1 point), has uppercase (1 point), has both lowercase and digit (1 point), and has special characters (1 point).
val score = passwordInput.passwordStrength()
when (score) {
    0, 1 -> showStatus("Weak Password", Color.Red)
    2, 3 -> showStatus("Medium Password", Color.Yellow)
    4 -> showStatus("Strong Password", Color.Green)
}

6. Credit Card Luhn Verification

Implements Luhn’s algorithm (mod 10 checksum) to validate credit/debit card numbers offline. Ignores spaces and dashes automatically, returning true if the structural digit sequence is valid:

val cardNumber = "4992-7398-716" // mock card input
if (cardNumber.isValidCreditCard()) {
    processPayment()
} else {
    showError("Invalid Credit Card Number")
}

7. Phone Number Utilities

Managed via the PhoneNumberUtils helper object in common code:

  • PhoneNumberUtils.isValid(phone: String): Checks if the phone number string conforms to standard length and digit properties.
  • PhoneNumberUtils.format(phone: String): Standardizes numbers for display (adds clean group separators like spaces and country indicators).
// Usage example
val rawPhone = "+919876543210"
val isValid = PhoneNumberUtils.isValid(rawPhone)
val displayVal = if (isValid) PhoneNumberUtils.format(rawPhone) else rawPhone // e.g. "+91 98765-43210"
