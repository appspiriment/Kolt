Library: utils

Collection & Formatting Utilities

Perform type-safe collection manipulations, clean metric representations, compact sizing strings, ordinals, and localized currencies.

1. Collection / List Operations

Modifiers on lists that avoid index bounds issues and simplify mutability in state flows:

  • List<T>.moveItem(fromIndex: Int, toIndex: Int): Re-orders an item in a list safely, returning a new immutable list. Useful for drag-and-drop lists.
  • List<T>.replaceFirst(predicate: (T) -> Boolean, transform: (T) -> T): Replaces the first matching item in a list using a transform function, returning a new copy of the list. Useful for modifying an item in an MVI state.
// Moving items in a list:
val items = listOf("A", "B", "C")
val reordered = items.moveItem(fromIndex = 2, toIndex = 0) // ["C", "A", "B"]

// Replacing a list item in state:
val updatedUsers = users.replaceFirst(
    predicate = { it.id == activeId },
    transform = { it.copy(isOnline = true) }
)

2. Compact Large Numbers

Converts large integers or longs into compact labels (e.g. for user view counts, download statistics, or likes count):

  • Long.toCompactString() (also available for Int):
    • 1_200.toCompactString() → "1.2K"
    • 1_500_000.toCompactString() → "1.5M"
    • 2_300_000_000.toCompactString() → "2.3B"

3. Number Formatting with Comma Separators

Formats numerical values into English-locale thousands-separated strings:

  • Int.toFormattedString() / Long.toFormattedString() / Double.toFormattedString(decimals = 2):
    • 1000.toFormattedString() → "1,000"
    • 10500.50.toFormattedString(decimals = 1) → "10,500.5"

4. File Sizes Formatting

Converts raw byte counts into readable storage sizes (using binary 1024-byte boundaries):

  • Long.toFileSizeString() (also available for Int):
    • 0.toFileSizeString() → "0 B"
    • 1024.toFileSizeString() → "1 KB"
    • 1_572_864.toFileSizeString() → "1.5 MB"

5. English Ordinal Suffixes

  • Int.toOrdinal(): Adds structural suffixes (st, nd, rd, th) to numbers:
    • 1.toOrdinal() → "1st"
    • 2.toOrdinal() → "2nd"
    • 11.toOrdinal() → "11th"
    • 21.toOrdinal() → "21st"

6. Percentage Strings

  • Double.toPercentString(decimals: Int = 1):
    • 0.425.toPercentString() → "42.5%"
    • 1.0.toPercentString() → "100%"
  • Int.toPercentString(total: Int, decimals: Int = 1): Calculates ratio automatically:
    • 42.toPercentString(total = 100) → "42%"

7. Duration Formatting

Converts duration counts in seconds to duration text segments:

  • Long.toDurationString() (also available for Int):
    • 65.toDurationString() → "1m 5s"
    • 3661.toDurationString() → "1h 1m"

8. Android Localized Currency Formatting

Exposed on Android targets in FormatUtils.kt, formatting currency values based on standard ISO codes:

// androidMain only
val costInDollars = FormatUtils.formatCurrency(amount = 299.99, currencyCode = "USD") // "$299.99"
val costInRupees = FormatUtils.formatCurrency(amount = 5000.0, currencyCode = "INR")  // "₹5,000.00"

9. Android Context & Intent Extensions

Extensions on Context that wrap standard Android operations:

  • context.launchPlayStorePage(packageName: String): Fires a market intent to launch the Play Store details page for an application. Falls back to a browser URL intent if the Play Store app is unavailable.
  • context.isNetworkAvailable(): Checks connectivity status using ConnectivityManager (requires ACCESS_NETWORK_STATE permission). Returns true if mobile, Wi-Fi, or ethernet routes are connected.
