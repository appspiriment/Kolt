Library: compose-utils

Keyboard & Dialer Actions

Disable soft keyboards dynamically for custom text entries and trigger telephone dialers or pre-formatted email templates directly on Android.

1. DisableSoftKeyboard (Keyboard Blocker)

When creating custom input fields (such as a secure PIN code number pad, mathematical calculators, or calendar dropdowns), focusing a Compose TextField triggers the system soft keyboard. This covers your custom inputs and disrupts the layout.

Wrap your inputs inside the DisableSoftKeyboard block container to intercept focus callbacks and block the soft keyboard from displaying.

Usage Example

@Composable
fun CustomPinPadScreen(viewModel: PinViewModel = viewModel()) {
    Column {
        // Wrap the standard or custom text fields inside this block:
        DisableSoftKeyboard {
            AppsTextField(
                value = viewModel.enteredPinCode,
                onValueChange = {},
                label = "Secure PIN"
            )
        }

        // Render your own grid of buttons underneath:
        PinNumberGrid(
            onNumberClick = { num -> viewModel.appendPinDigit(num) },
            onBackspace = { viewModel.removeLastDigit() }
        )
    }
}

2. PhoneActionUtils (Dialer & Mailer Intents)

Direct helper extensions on the Android Context layer to launch communication apps with pre-populated fields.

Dial a Phone Number

Context.dialNumber(phone: String) constructs and launches an intent with the action Intent.ACTION_DIAL. It loads the dialer app and pre-fills the number, requiring the user to tap the call button (does not require call permissions).

val context = LocalContext.current

AppsButton(
    text = "Call Support".toUiText(),
    onClick = {
        context.dialNumber("+18005550199")
    }
)

Send a Formatted Email

Context.sendEmail(to: String, subject: String, body: String) launches an email client intent (pre-filling target address, subject lines, and body blocks):

AppsButton(
    text = "Send App Feedback".toUiText(),
    onClick = {
        context.sendEmail(
            to = "support@appspiriment.io",
            subject = "Feedback - Kolt monorepo",
            body = "Hi team,\n\nI have the following feedback..."
        )
    }
)
