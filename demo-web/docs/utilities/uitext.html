Library: compose-kmp

UiText

Represent platform-dependent text resources—such as raw strings, XML resource IDs, quantity plurals, and rich annotated strings—as unified models in common, platform-agnostic business logic.

1. Overview & Why It Is Needed

In Kotlin Multiplatform (KMP), business logic (ViewModels, repositories, and interactors) lives in the commonMain source set. However, resources like localized string XML files (e.g. strings.xml) are highly platform-dependent. Referencing Android resource integer IDs (e.g., R.string.error_message) directly in common code breaks compilation for iOS, Desktop, and Web targets.

UiText solves this issue by acting as an abstraction barrier. ViewModels represent text as instances of the UiText sealed class and deliver them to the UI layer. Only inside the Composable tree (where a platform Context or localization manager is active) is the UiText resolved into a native platform string.

2. Class Definition & Subclasses

UiText is structured as a sealed class with five specialized subclasses that cover all standard text formatting requirements.

package io.github.appspiriment.kolt.composekmp.wrappers

sealed class UiText {
    companion object {
        val Empty: UiText = DynamicString("")
    }
    
    // ... subclasses
}
Subclass Parameters Description & Use Cases
DynamicString val value: String Wraps a hardcoded raw string. Useful for server-provided content, input values, and temporary debug messages.
StringResource val resId: Int
vararg val args: Any		 Wraps an XML string resource ID. Accepts optional format arguments (e.g. %s placeholders), which themselves can be raw values or other nested UiText instances.
PluralResource val resId: Int
val quantity: Int
vararg val args: Any		 Wraps a quantity (plurals) string resource. Resolves correct grammatical forms dynamically based on locale definitions.
StringArrayResource val resId: Int Wraps a string array resource ID. Useful for populating selection dropdowns, spinner lists, or static option tabs.
DynamicAnnotatedString val value: AnnotatedString Wraps a Compose-specific AnnotatedString containing custom character styling, colors, or inline links.

3. Factory Extensions & Helpers

Kolt provides standard extension functions on top of common Kotlin types to instantly convert values into UiText wrappers with minimal syntax overhead:

// Convert raw types directly:
"Hello".toUiText()                // -> UiText.DynamicString
42.toUiText()                     // -> UiText.DynamicString
annotatedString.toUiText()        // -> UiText.DynamicAnnotatedString

// Null-safe conversion helpers:
val message: String? = null
message.toUiTextOrEmpty()         // -> Returns UiText.Empty (empty DynamicString)
message.toUiTextOrElse { "Default" }

// Conditional fallbacks:
message.toUiTextOr { UiText.StringResource(R.string.fallback_label) }

4. Resolving inside Composables

Once a UiText object is passed from the ViewModel to the Composable tree, it can be resolved into a native string using platform-aware Composable extension functions:

  • UiText.asString(): String: Resolves the wrapper and processes formatting arguments, returning a native String.
  • UiText.asStringList(): List<String>: Resolves a string array resource, returning a standard Kotlin list of strings.
  • UiText.asAnnotatedString(formatHtml: Boolean = false): AnnotatedString: Resolves the text into a styled AnnotatedString. Setting formatHtml = true automatically parses basic HTML styling tags (such as <b>, <i>, and <u>) into Compose styles.

5. Complete Code Example

This implementation demonstrates a profile state flow that resolves localized placeholders inside a common ViewModel and binds it to a Jetpack Compose screen.

1. ViewModel (commonMain)

import io.github.appspiriment.kolt.composekmp.wrappers.UiText
import io.github.appspiriment.kolt.utils.state.AsyncState
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow

class UserProfileViewModel : ViewModel() {
    private val _welcomeState = MutableStateFlow<AsyncState<UiText>>(AsyncState.Idle)
    val welcomeState: StateFlow<AsyncState<UiText>> = _welcomeState

    fun loadUser(username: String, notificationCount: Int) {
        _welcomeState.value = AsyncState.Loading
        
        // Nested wrapping: format string with a plural string argument
        val notificationText = UiText.PluralResource(
            resId = R.plurals.new_notifications,
            quantity = notificationCount,
            notificationCount
        )
        
        val greeting = UiText.StringResource(
            resId = R.string.welcome_greeting,
            username,
            notificationText // UiText works as format argument!
        )
        
        _welcomeState.value = AsyncState.Success(greeting)
    }
}

2. Composable Screen (commonMain UI / androidMain)

import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.collectAsState
import io.github.appspiriment.kolt.composekmp.wrappers.asString

@Composable
fun UserProfileScreen(viewModel: UserProfileViewModel) {
    val state = viewModel.welcomeState.collectAsState().value
    
    when (state) {
        is AsyncState.Loading -> {
            Text("Loading welcome message...")
        }
        is AsyncState.Success -> {
            // Resolves the UiText resource and formatting arguments on-the-fly
            Text(
                text = state.data.asString(),
                style = Kolt.typography.headingMedium,
                color = Kolt.colors.textPrimary
            )
        }
        is AsyncState.Error -> {
            Text("Failed to load user state: ${state.throwable.message}")
        }
        else -> {}
    }
}
